Motovra – Premium Car Detailing Website

Project Overview

Motovra is a car detailing website designed to present professional vehicle cleaning and detailing services. It provides visitors with information about the business, available services, and an online booking form.

Features

- Home page with an introduction to the business
- Services page describing detailing services
- About page with business information
- Online booking form
- Google Sheets integration for booking records
- Google Apps Script logic for checking duplicate booking slots
- Responsive website design

Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets

Project Type

Frontend website with Google Apps Script and Google Sheets integration for booking management.

Repository Contents

- "index.html" – Home page
- "about.html" – About page
- "services.html" – Services page
- "booking.html" – Booking page
- "images/" – Website images
- "code.gs" – Booking backend script

How to Run

Download or clone the repository and open "index.html" in a web browser. Booking functionality may require the configured Google Apps Script deployment and Google Sheets access.

Purpose

This project was developed to demonstrate website design, frontend development, and basic booking workflow integration.
